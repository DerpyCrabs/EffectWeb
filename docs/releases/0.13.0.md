# EffectWeb 0.13.0

EffectWeb 0.13 adds route-tree rendering to the TanStack Router adapter, bridges Effect atoms to views, and improves DOM lifetime composition and update skipping. This is a breaking pre-1.0 release. Upgrade `effectweb` and every `@effectweb/*` package together to `0.13.0`.

## Breaking changes

- `@effectweb/tanstack-router.mountRouter(router)` now returns a `RouterController`, rather than a `Source`. Read and subscribe through `controller.source`; render its matched route tree with `RouterView`. The mounted controller remains owned by its Effect scope.
- Base UI NumberField values and callbacks accept `number | null`; an omitted initial value is empty rather than zero. Code that requires a number must handle the empty state or supply `defaultValue`.
- Base UI menu checkbox and radio items stay open after selection by default. Set `closeOnClick` when selection should dismiss the menu.
- `ToastData.title` is optional, titles and descriptions accept JSX, and `type` accepts custom strings. Consumers that read toast data must handle these wider types.

## Runtime

- `atomSource(registry, atom)` exposes an Effect atom as a shared Source and keeps its subscription owned by the consuming view or controller.
- `composeMounts` combines independent DOM bindings in one `use` slot. Composed bindings use the renderer's Effect runtime, report errors through its error handler, and join asynchronous finalizers when the mounted tree closes. Reentrant updates and replacement bindings retain the same lifetime guarantees as individual bindings.
- Error boundary resets release the failed render's lifetime before mounting its replacement. Publications during disposal no longer revive removed children.
- Mapped sources reuse selector results for unchanged producer snapshots without retaining obsolete root snapshots. Component updates skip unchanged inline prop captures, and valid scalar attributes avoid constructing unused diagnostic strings.

## Router and query adapters

- The router adapter supplies route factories, lazy route components, route scopes and nested outlets, with pending, error and not-found rendering. Explicitly disabled pending components remain disabled, and lazy preloads reuse their resolved modules during navigation.
- Query sources release unused shared entries, including sources created without a subsequent read or subscription, while preserving sharing between active observers.

## Base UI

- Overlay parts compose caller DOM bindings with their own lifetimes. Portal placement, focus options, open-change details and collision handling extend the existing parts without requiring a separate overlay runtime.
- NumberField preserves intermediate localized edits and composition text, formats and clamps on blur, and handles controlled parent acceptance or rejection without duplicate change requests.
- Adding a toast with an existing ID refreshes its auto-dismiss duration, including paused timers. Queued toasts start their timers only when promoted. Toast data supports custom payloads, actions and close/remove callbacks.
- Presence cleanup reports rejected asynchronous close handlers through the runtime error handler.

## Compiler and verification

- Builds stage JavaScript, generated icons, declarations and packaged documentation before replacing outputs. Failed builds preserve the previous complete outputs; package smoke tests exercise composed lifetimes and router rendering from installed tarballs.

- Inline component arrow functions, object literals and array literals carry their call-site identity and captured values so unchanged props can skip rendering. `EW3004` also flags `projectionSource` creation inside views, where recreating the source would discard observation identity.
- Workspace unit and browser tests default to two workers to bound memory use on machines with many CPU cores. File and browser-page isolation remain enabled; command-line worker options can override the defaults.
