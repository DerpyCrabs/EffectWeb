# EffectWeb 0.14.0

EffectWeb 0.14 completes the adapters: TanStack Router links preload and mark themselves active, navigation can be blocked, TanStack Form exposes form-core's validators, fields and array helpers, Base UI gains its remaining families, and shadcn ports the components upstream builds on React-only libraries. It also adds opt-in profiling and DOM measurement lifetimes. This is a breaking pre-1.0 release. Upgrade `effectweb` and every `@effectweb/*` package together to `0.14.0`.

## Breaking changes

- `@effectweb/tanstack-form.createForm` takes TanStack Form Core's options (`validators`, `listeners`, `asyncDebounceMs`, `canSubmitWhenInvalid`, `onSubmitInvalid`) instead of `validate` and `validateAsync`, and publishes TanStack's form state (`errors`, `errorMap`, `fieldMeta`, `isValid`, `canSubmit`, `isSubmitting`, `isSubmitSuccessful`, `submissionAttempts`) plus `submitError`. `setField` is `setFieldValue` or `handleChange`; `setTouched` is `handleBlur`; `onError` is optional. `createField` mounts a field with its own validators and listeners.
- `@effectweb/tanstack-router` links are active by default against the router's location, with `activeOptions`; the `active` prop now overrides that computation. Links preload per `preload` or the router's `defaultPreload`, which routers that set `defaultPreload` start doing on upgrade.
- `@effectweb/shadcn` `CommandItem` runs `select`, not `onSelect`, because `onselect` is a native event.

## Runtime

- DOM bindings acquire deepest element first in one microtask, so a binding that measures its element sees its descendants' bindings applied; a binding that republishes schedules replacements for the next microtask as before.
- `effectweb/profiling` installs bounded performance attribution in development; the Vite plugin's `profile` option injects it. `DomLifetime.measure` sequences layout reads and writes across independent bindings.

## Router and form adapters

- `createBlocker` blocks navigation with an optional resolver state; `matchRoute` and `canGoBack` publish match and history state; the router's `scrollRestoration` option is honoured. `linkPreloadBinding` and `isActiveLocation` give custom anchors the link's behavior.
- `createForm` and `createField` wrap TanStack Form Core's `FormApi` and `FieldApi`, including array helpers, with an Effect-aware `submit`.

## Base UI

- New families: CheckboxGroup with a parent checkbox, Meter, OTPField, PreviewCard, and Form with external field errors. Closed Select scroll arrows no longer read layout on window scroll.

## shadcn

- New components: ButtonGroup, InputOTP, Resizable, Carousel, Command, Calendar and Form. Command, Calendar, Carousel, Resizable and InputOTP are native ports of cmdk, react-day-picker, embla-carousel, react-resizable-panels and input-otp; Chart is not ported.
