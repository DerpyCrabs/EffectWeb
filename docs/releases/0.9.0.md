# EffectWeb 0.9.0

EffectWeb 0.9 simplifies UI state and owned work, improves compiled rendering, expands form validation, and adds a complete static documentation site. This is a breaking pre-1.0 release. Upgrade `effectweb` and every `@effectweb/*` package together to `0.9.0`.

## Highlights

- Components support local fields and named-message updates. Controllers share feature state and actions through a source; `controllerView` manages their placement and lifetime.
- Owned work uses structural keys and explicit concurrency policies. `owner.task` publishes loading, success and failure through Effect's `AsyncResult`; returned run handles expose completion and cancellation.
- The compiler records dependencies of analyzable inline list callbacks and compiles nested markup into reusable templates. Unchanged rows can skip rendering while rows reading their index update correctly after reordering.
- TanStack Form now supports cancellable async validation and touched, dirty and error state per field. Submission validates the current draft before saving; obsolete checks cannot overwrite newer results.
- JSON-render preserves element identity, input drafts, focus and selection when children move. Router teardown cancels loaders, before-load hooks and preloads, and settles pending navigation.
- Runtime fixes cover task finalizers, live-source subscriptions, snapshot protection, template styles and native event propagation.
- The new documentation includes setup, conceptual explanations, task guides, generated API reference, search and checked examples. It generates static HTML and includes Netlify build configuration.

## Migrating from 0.8.x

### Mounting and ownership

- Rename synchronous `mountView(parent, view, input)` to `mount(parent, view, input)`.
- Rename the Effect-returning `mount(...)` to `makeMount(...)`, and yield it inside an Effect scope. Calling it as a plain statement does not mount anything.
- Replace `makeModelOwner` and `makeProgram` with `modelOwner` and `program`. When acquiring one inside an Effect scope, register `close()` as its release action with `Effect.acquireRelease`.
- Replace `lifetime()` with `modelOwner({})` for an owner without application state.
- Mounting a source or controller does not transfer its ownership. Dispose it yourself, or use `controllerView` for a controller owned by its place in the UI.

### Components and tasks

- Replace `localComponent` with `component({ init }, view((model, patch) => ...))`. Parent props are available as `model.props`.
- Use `controllerView({ controller, identity }, view)`; the factory property was previously `create`.
- Replace `defineTasks` / `ownedTasks` with owner `run` or `task` calls. Inside a local-fields component, obtain its owner with `ownerOf(patch)` in an event handler.
- Replace command slots with `RunKey`: a string, number, or readonly array of them. Change command objects from `slot` to `key`. Array keys are compared structurally within an owner.
- Replace `actionCommand` / `effectCommand` with command objects `{ key, policy, effect }`. The Effect's success becomes the next message; handle its error channel explicitly.
- `owner.run` starts immediately and returns an `OwnedRun`. Its `await` Effect yields the run's `Exit`; use `awaitIdle` to wait for owner work or `close` to wait for teardown.
- Replace `effectEvent` with an Effect returned directly from an event handler for simple actions, or an owner task when concurrency policy matters.
- Replace `AsyncContent` with `available(result)`, `resourceError(result)` and `result.waiting`. `AsyncResult` comes from `effect/reactivity/AsyncResult`.
- Runtime execution helpers formerly exposed at the root (`uiRuntime`, `makeUiRuntime`) are no longer part of the public authoring API. Use owners, event Effects and `makeMount` with services instead.

### Lists, queries and adapters

- Render JSX rows with `list(values, render)` for scalars, `list(entities(rows), render)` for objects with IDs, or `list(rows, identity, render)`. JSX-returning `.map` callbacks now produce lint errors, including static rows.
- Replace `makeQueryCache` / `scopedQueryCache` with `queryCache(context)`. Own its `close()` explicitly, or register it through an Effect scope.
- Router links reject unimplemented `preload`, `preloadDelay`, `preloadIntentProximity` and `activeOptions` props. Use `router.preloadRoute` explicitly and supply `active` from your route model.
- Mount a router only once. After its scope closes, loading, navigation and preloading reject instead of starting unowned work.
- Form snapshots now include `fields`, `validating` and `validationError`. Async validators return Effects of field-path errors. Edits, replacement, reset and disposal cancel obsolete validation; submission waits for a valid draft.

The repository's `scripts/migrate-api-0.9.mjs` assists with selected row, key and controller rewrites; it is not a complete migration. It requires the TypeScript 6 compiler API, supplied through `TYPESCRIPT_API` when the workspace uses TypeScript 7. Review its changes and run application checks afterward.

## Requirements and limitations

- Effect 4, Node.js 22.14+ for compiler tooling, and TypeScript 5.4+.
- Native compiler packages cover glibc Linux x64/arm64, macOS x64/arm64, and Windows x64. No prebuilt musl package.
- The UI runtime renders in the browser; SSR and hydration are not provided. The documentation site uses a separate static HTML build.
- Form validation covers the whole draft; individual field validators and automatic debounce remain application-owned. JSON-render repeat scopes and state watchers are not implemented.

## Validation

Local validation passed 961 unit tests, 88 browser tests, checked documentation examples, lint/type/Clippy checks, static-site checks and clean-package smoke tests. The affected local adapter consumers passed their checks, builds and available tests against rebuilt packages. The release workflow gates npm publishing on CI and native builds for all five supported platforms.
