# EffectWeb 0.16.0

## Migration

The compiler now reports EW3002 when a local factory called from a JSX `use` prop returns a DOM binding with a fresh inline setup function. Each render previously replaced the setup and could restart listeners, observers or timers. Move the setup to module scope and pass changing data through `domBinding(data, setup)`. If changing the underlying resource requires reacquisition, give the binding that resource with `domBinding(data, setup, { identity: resource })`.

A binding that only updates the element can now return `{ update }`. Add a `dispose` method when the binding acquires a resource that needs cleanup.

Per-row tasks now check both the ID and the result type of the selected entry. EW1007 reports writes to locally identifiable snapshot records and arrays. Publish replacements with `owner.patch` or `owner.edit`.

Controllers that forward props directly can return `{ ...ownerController(owner), save }`. The helper supplies the source, prop receiver and lifetime. For argument-free queries, use `resource.select()` or `querySource(cache, definition)`; `resource.clear()` disconnects any selection. Form views can read a typed field from their current snapshot with `getSnapshotValue(snapshot, path)`. Use `form.snapshotValues()` to borrow the current draft for another immutable projection, including same-turn edits. Use `form.values()` when you need an independently editable copy.

## Browser hosts

Use `viewWindow(host)` in a controller or `viewWindow(element)` in a DOM binding to access the owning window. Base UI uses the owning document for native dialogs, focus, observers and event listeners. A file input canceling its picker leaves its containing dialog open. Escape still dismisses the dialog and restores focus to its trigger.

## Positioning

Open overlays skip geometry reads when a scroll occurs outside both the anchor and popup ancestry. A regression test dispatches 100 sibling scrolls and expects zero anchor measurements, followed by one measurement for a scroll on the anchor's ancestor. Virtual anchors without a context element continue to reposition on scroll.

## Adapters and component catalogs

Infinite queries can prepend earlier pages while a later page is loading. JSON Render supports keyed repeats, named slots and state watches. TanStack Form uses registered field validators for form-level edits and clears submission errors on array changes. Router links accept native click cancellation, follow changing preload destinations and preserve consumer DOM bindings. Keycloak reads display names from both token profiles.

The shadcn registry adds transcript, chart, questionnaire, input-group, table, date-picker, direction, typography and toast entries. Ant Design now includes all 150 TwoTone modules in its pinned catalog.
